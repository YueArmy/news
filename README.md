# 朝刊 — AI・心理学・マーケティング

ゆや専用の毎朝ニュースサイト。Muse が毎朝 8:00 (JST) に更新し、GitHub Pages で公開する想定。

## 運用ルール
- 読む負荷は5分。冒頭の「今日のポイント」は、それだけで号全体の地図がつかめる具体文で書く（専門用語の圧縮は禁止）。
- 本文も同じルール：専門用語は最初に出たところで普通の言葉で言い直す（例：worktree＝プロジェクトのコピーを作って別々に作業する仕組み）。馴染みのない難しい語彙で圧縮しない。前の段落を読んでいないと意味が取れない書き方をしない。
- 選定基準：コード／設定／数字／再現手順のどれかという具体物があるものだけ。
- カテゴリ：AI（毎日）／心理学（隔日・一次情報優先）／マーケティング（隔日・数字のある事例優先）／日曜は週次統合。
- メモはこのリポジトリに入れない。Google Sheets（非公開）側に置き、返しは翌朝の号に載せる。

## 構成
- `index.html` 今日の号への入口
- `issues/YYYY-MM-DD.html` 各号
- `category/` カテゴリ別一覧
- `archive.html` / `stock.html`
